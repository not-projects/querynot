# QueryNot Brand Decision

Date: 2026-08-12
Status: Approved naming direction

## Product name

**QueryNot**

QueryNot is a smooth, effective, and simple desktop SQL client. The name uses an action associated with the product—querying data—and the shared `Not` suffix of the Not Projects product family.

## Primary tagline

> Query your data, not your patience.

The tagline states the product's job and contrasts it with the friction that QueryNot is intended to remove.

## Brand family

- Organization handle: `not-projects`
- Organization display name: **Not Projects**
- Existing product: **PostNot**
- New product: **QueryNot**
- Recommended repository name: `querynot`

Product names use PascalCase and end in `Not`. GitHub organization and repository identifiers use lowercase names suited to URLs, package metadata, CI, and terminal commands.

## Naming rationale

- `Query` is an immediately recognizable database action.
- The action-first construction mirrors PostNot's use of `Post` for sending requests.
- The name is database-engine-neutral and does not limit the client to a specific SQL dialect.
- Unlike `SelectNot`, it does not imply a read-only client.
- The shared `Not` suffix establishes a recognizable family for products that will eventually share design solutions and, where practical, a reusable UI framework.

## Scope of this decision

This document approves only the product name, tagline, and family naming conventions. Product architecture, feature scope, visual-system extraction, and implementation planning remain separate decisions.
