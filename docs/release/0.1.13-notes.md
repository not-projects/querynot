# QueryNot 0.1.13

This patch release keeps connection startup responsive and makes compatibility and query failures easier to handle inside the workbench.

Highlights:

- starts SQL-completion metadata warmup only after connection and tab-session readiness, then continues it asynchronously without keeping the profile in Connecting or blocking ordinary interaction;
- prevents stale background metadata from repopulating completion caches after a refresh, context change, disconnect, or reconnect;
- lets users dismiss an out-of-matrix compatibility warning for the current connection without changing its read-only or capability restrictions; and
- presents rejected query starts and database execution failures in Results with a readable category, safe database message, statement location when available, and cause-specific guidance.

QueryNot remains local-first and sends no telemetry or database information. Connection credentials, direct database access, native session isolation, query-history persistence, TLS verification, destructive-query safeguards, file boundaries, and updater-signing boundaries are unchanged.

Updater signatures authenticate release payloads but are not Windows Authenticode, Apple Developer ID/notarization, or Linux repository signatures. Windows may show an unknown-publisher warning, macOS may require its per-application Open Anyway flow for the unnotarized build, and Linux desktop or package tools may show an untrusted-source warning. Do not disable an operating-system security control globally; verify the downloaded installable package against `SHA256SUMS` before installation.

The platform and database matrix is unchanged from 0.1.12: Windows 11 x86-64, Linux x86-64 through AppImage/DEB/RPM, macOS 13 or later on Intel and Apple silicon, SQLite format 3, and the published MySQL/MariaDB fixture matrix. Native hardware, Windows Narrator/WebView2 UI Automation, operating-system Contrast Themes, vault, performance, dogfood, and external beta observations remain follow-up evidence rather than release claims.
