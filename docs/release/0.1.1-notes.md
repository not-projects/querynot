# QueryNot 0.1.1

This Windows 11 x86-64 maintenance release makes the workbench usable across larger windows and every included theme, corrects completed-dialog and query-result behavior, restores safe native window closing, and introduces QueryNot's signed in-application update channel.

Highlights:

- repaired the bottom status bar, opaque dialogs, themed dropdowns, sidebar overflow, complete UI scaling, completed-action dialog dismissal, and terminal query timing/result presentation;
- opened schema starter queries in a new tab on an existing connected profile and moved compact history below the schema explorer;
- aligned theme names and the new open-`Q` application icon with the PostNot product family;
- added a silent signed update check plus manual check and explicit installation controls in Settings; and
- added a fail-closed, no-rebuild release workflow that publishes the exact NSIS installer, updater signature, `latest.json`, and manual `SHA256SUMS` checksum reviewed in candidate CI.

The updater signature is not Windows Authenticode signing, so Windows may still show the unsigned-publisher warning documented in the installation guide. QueryNot `0.1.0` did not contain an updater and must be upgraded to `0.1.1` manually. In-application signed updates apply to releases after `0.1.1`.

QueryNot remains local-first and sends no telemetry or database information. An update check makes an HTTPS request only to QueryNot's stable GitHub Releases feed. Installation saves recovery drafts and refuses to proceed while a connection setup, query, transaction, or staged table edit is unresolved.

Support remains Windows 11 x86-64 with the SQLite, MySQL, and MariaDB matrix documented in the compatibility matrix. Windows 10, macOS, native Linux distribution, additional engines, cloud synchronization, accounts, telemetry, and external beta expansion remain unsupported or post-release work unless separately approved.
