# QueryNot 0.1.16

This release makes estimated query plans faster to scan with a graph-first Explain workflow and optional, local-only relative estimate highlighting. It also keeps connection compatibility warnings contained at constrained window sizes and high interface scales.

Highlights:

- opens normalized plans with a dependency-free top-down **Graph** when they contain up to 250 nodes, while preserving Tree as the complete linear alternative and Raw as the lossless engine payload;
- adds 50–150% graph zoom, structural keyboard navigation, scrolling, and a factual node inspector containing every normalized field;
- adds off-by-default **Experimental plan hotspot estimates** under Results & tables, using reported total cost when sufficiently covered and otherwise reported estimated rows;
- presents lower, middle, and upper-quartile relative bands with textual labels, metric coverage, and the three highest reported values so meaning never depends on color alone;
- explains the non-executing, within-plan-only workflow through an information control beside Explain, with direct keyboard-safe access to the focused setting; and
- keeps MySQL compatibility warnings and header controls inside the window while a connection is opening at constrained widths and high UI scales.

Hotspot estimates are derived only from valid, finite, non-negative values in the current plan. They are not query-quality scores, tuning recommendations, actual runtime measurements, or elapsed-time predictions. Plans without enough comparable values remain neutral and state that relative estimates are unavailable.

QueryNot continues to request estimated plans only. It never generates `EXPLAIN ANALYZE` for this feature, executes no second prediction request, and does not persist plan payloads, graph state, or derived rankings in History or operational logs.

PostgreSQL remains a development preview. Its dedicated PostgreSQL 18.6 conformance fixture and support evidence are still pending, so this release does not add PostgreSQL to the supported database matrix.

The supported platform and database matrix remains unchanged from 0.1.15: Windows 11 x86-64, Linux x86-64 through AppImage/DEB/RPM, macOS 13 or later on Intel and Apple silicon, SQLite format 3, and the published MySQL/MariaDB fixture matrix. Native hardware, Windows Narrator/WebView2 UI Automation, operating-system Contrast Themes, vault, performance, dogfood, and external beta observations remain follow-up evidence rather than release claims.

Updater signatures authenticate release payloads but are not Windows Authenticode, Apple Developer ID/notarization, or Linux repository signatures. Windows may show an unknown-publisher warning, macOS may require its per-application Open Anyway flow for the unnotarized build, and Linux desktop or package tools may show an untrusted-source warning. Do not disable an operating-system security control globally; verify the downloaded installable package against `SHA256SUMS` before installation.
