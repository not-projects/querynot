# QueryNot 0.1.2

This Windows 11 x86-64 maintenance release repairs the core query workbench: first-run results appear immediately, local database files enter through the normal connection flow, application close behavior is quiet and safe, and the editor/results workspace is compact and resizable.

Highlights:

- reconciled early native result batches so populated and zero-row results appear on the first execution;
- unified connection creation behind Server/File, with explicit file selection, a read-only SQLite probe, and opaque native file grants;
- moved SQL document actions into a compact File menu and added a persisted, keyboard-accessible 20–70% editor/results split with one virtualized result viewport;
- replaced the redundant close dialog with silent safe close while keeping actionable work focused and protected;
- kept normal typing focused by making healthy draft-recovery debounce silent and reserving its banner for actual persistence failures;
- restored unsigned development startup with an inert updater configuration while preserving fail-closed signed release injection; and
- added independent Ed25519-BLAKE2b verification of the updater installer and trusted comment before publication.

QueryNot remains local-first and sends no telemetry or database information. Database files are selected explicitly; the application does not scan the filesystem for databases. Creating a new SQLite database remains deferred.

The updater signature is not Windows Authenticode signing, so Windows may still show the unsigned-publisher warning documented in the installation guide. Installation saves recovery drafts and refuses the handoff while connection setup, a query, transaction, or staged table edit is unresolved.

Support remains Windows 11 x86-64 with the SQLite, MySQL, and MariaDB matrix documented in the compatibility matrix. Windows 10, macOS, native Linux distribution, additional engines, cloud synchronization, accounts, telemetry, and external beta expansion remain unsupported or post-release work unless separately approved.
