# QueryNot 0.1.17

This version improves connection reliability, query editing, and everyday desktop interaction. Its source and release notes are prepared for review; signed packages and updater publication are pending.

Highlights:

- adds **Test connection** to Add and Edit connection, probing current form values through a temporary native connection without saving a profile or credentials;
- checks idle server connections every 30 seconds and on window focus after an explicit Connect, recovering clean sessions with their original context and transaction mode;
- opens and switches query tabs immediately, allocating an isolated SQL session only when Run, Explain, an explicit context change, or a transaction action needs it;
- keeps SQL editor focus, caret, and selection when executing with Control+Enter or Command+Enter;
- copies a focused result cell's complete canonical raw value with Control+C or Command+C while retaining double-click copy;
- shows bounded database syntax and missing-object diagnostics for queries and Explain, including MySQL vendor numbers and SQLSTATE and PostgreSQL statement positions when supplied;
- removes routine version notices for supported MySQL 5.7.x and PostgreSQL 18.x while retaining actionable transport, read-only-server, and unsupported-version warnings;
- remembers normal window bounds and maximization, clamps restored bounds to available monitor work areas, and safely ignores invalid saved geometry; and
- refines the Q and query dot in the application icon while preserving the original Not Projects tile and palette across platform assets.

Connection recovery never replays SQL, refetches old results, or applies staged mutations. Active work and native mutation plans are protected, and background checks pause during staged editing. A lost Active or Unknown transaction requires review and explicit Retry before execution can resume. Disconnect cancels in-flight recovery and prevents reconnection. Restored workspaces start offline; the old automatic-reconnect setting is removed. Endpoint and security edits apply after explicit reconnect, while temporary Test connection probes use the current form values.

Validation used the existing WSL application through `npm run tauri dev`, with real SQLite and a marker-verified disposable MySQL 8.0.46 fixture over verified TLS. No standalone builds or release/conformance suites were run. Live PostgreSQL and native Windows/macOS validation remain pending; WSLg did not honor absolute window-position requests.

Dependency remediation updates stable Tauri and the pinned updater, replaces the vulnerable ZIP dependency, and refreshes TLS, runtime, constant-time utility, and frontend tooling dependencies. Advisory and severity gates remain enabled; the dependency risk register records only the remaining reviewed informational maintenance exceptions.

The published support matrix is unchanged. PostgreSQL remains a development preview with its dedicated PostgreSQL 18.6 conformance and support evidence still pending. This source version does not establish a new packaging, hardware, accessibility, vault, performance, dogfood, or beta claim.
