# QueryNot 0.1.8

This release makes Connections, Schema, and local History easier to scan while keeping their existing database, metadata, and query-reopen behavior intact. It also reduces the routine cost of reviewing and publishing an already validated signed release candidate.

Highlights:

- gives saved connections a compact two-line hierarchy with explicit Connected, Offline, Testing, and Connecting states plus consistent primary and overflow actions;
- keeps Connections and Schema within the persisted split while aligning their headings, icon controls, row density, and selection treatment;
- makes schema copy, query, and refresh actions available on demand without giving secondary controls permanent visual emphasis;
- reorganizes local History into readable query records with clearer status, timestamp, duration, row-count, reopen, delete, search, and empty states;
- keeps local-history storage guidance available through progressive disclosure instead of competing with the query list; and
- streamlines signed release automation by reusing successful exact-commit CI, retaining review artifacts briefly, checking GitHub-computed asset digests, and reserving full-package downloads for an explicit deep audit.

QueryNot remains local-first and sends no telemetry or database information. Connection credentials, database access, query-history persistence, schema loading, query reopening, TLS verification, destructive-query safeguards, and updater-signing boundaries are unchanged.

Updater signatures authenticate release payloads but are not Windows Authenticode, Apple Developer ID/notarization, or Linux repository signatures. Windows may show an unknown-publisher warning, macOS may require its per-application Open Anyway flow for the unnotarized build, and Linux desktop or package tools may show an untrusted-source warning. Do not disable an operating-system security control globally; verify the downloaded installable package against `SHA256SUMS` before installation.

The platform and database matrix is unchanged from 0.1.7: Windows 11 x86-64, Linux x86-64 through AppImage/DEB/RPM, macOS 13 or later on Intel and Apple silicon, SQLite format 3, and the published MySQL/MariaDB fixture matrix. Native hardware, vault, accessibility, performance, dogfood, and external beta observations remain follow-up evidence rather than release claims.
