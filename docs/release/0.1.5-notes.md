# QueryNot 0.1.5

This release expands QueryNot's signed desktop distribution beyond the current Windows-only `0.1.4` release while preserving the same local-first database, credential, file, and updater boundaries.

Highlights:

- adds Windows x86-64 NSIS and MSI packages;
- adds Linux x86-64 AppImage, Debian, and RPM packages;
- adds macOS 13-or-later DMGs for Intel and Apple silicon;
- publishes one combined signed updater manifest covering Windows, Linux, macOS Intel, and macOS Apple silicon;
- verifies every updater payload and every installable-package checksum before candidate retention, before draft creation, and after the draft is downloaded; and
- uses Command shortcuts on macOS while retaining Control shortcuts on Windows and Linux, with matching labels and accessibility metadata.

QueryNot remains local-first and sends no telemetry or database information. Existing Windows `0.1.1`–`0.1.4` installations can discover `0.1.5` through the same dedicated QueryNot updater identity. New macOS and Linux installations join that signed update channel after the first manual install.

Updater signatures authenticate release payloads but are not Windows Authenticode, Apple Developer ID/notarization, or Linux repository signatures. Windows may show an unknown-publisher warning, macOS may require its per-application Open Anyway flow for the unnotarized build, and Linux desktop or package tools may show an untrusted-source warning. Do not disable an operating-system security control globally; verify the downloaded installable package against `SHA256SUMS` before installation.

The prepared platform matrix is Windows 11 x86-64, Linux x86-64 through AppImage/DEB/RPM, and macOS 13 or later on Intel and Apple silicon. Windows 10, Linux ARM, additional engines, SSH tunnelling, accounts, telemetry, cloud synchronization, and external beta expansion remain outside this release unless separately approved.
