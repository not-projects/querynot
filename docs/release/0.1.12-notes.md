# QueryNot 0.1.12

This patch release makes the compact SQL workspace easier to use and prepares schema-aware completion before typing begins.

Highlights:

- keeps the SQL editor scrollable when Results is dragged to its maximum supported size by retaining a three-and-a-half-row editor viewport, including horizontal-scrollbar space;
- preloads the active database/schema's table and view names plus a bounded set of column metadata when a connection or query-tab context becomes active;
- reuses that metadata for schema navigation and SQL completion without opening extra query execution sessions; and
- retains on-demand referenced-object lookup when a catalog exceeds the preload bound or metadata is temporarily unavailable.

QueryNot remains local-first and sends no telemetry or database information. Connection credentials, direct database access, native session isolation, query-history persistence, TLS verification, destructive-query safeguards, file boundaries, and updater-signing boundaries are unchanged.

Updater signatures authenticate release payloads but are not Windows Authenticode, Apple Developer ID/notarization, or Linux repository signatures. Windows may show an unknown-publisher warning, macOS may require its per-application Open Anyway flow for the unnotarized build, and Linux desktop or package tools may show an untrusted-source warning. Do not disable an operating-system security control globally; verify the downloaded installable package against `SHA256SUMS` before installation.

The platform and database matrix is unchanged from 0.1.11: Windows 11 x86-64, Linux x86-64 through AppImage/DEB/RPM, macOS 13 or later on Intel and Apple silicon, SQLite format 3, and the published MySQL/MariaDB fixture matrix. Frontend, Chromium, contract, traceability, formatting, dependency-policy, and production-build checks passed during development. Native hardware, Windows Narrator/WebView2 UI Automation, operating-system Contrast Themes, vault, performance, dogfood, and external beta observations remain follow-up evidence rather than release claims.
