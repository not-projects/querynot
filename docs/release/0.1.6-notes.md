# QueryNot 0.1.6

This release makes QueryNot denser and more adaptable during everyday database work, and enables the existing guarded write workflows for well-formed MySQL 5.7.x server versions.

Highlights:

- enables ordinary writes, manual transactions, and safe staged row mutations across well-formed MySQL 5.7.x patch versions while retaining the legacy warning and all existing safety controls;
- keeps MySQL 5.7.44 as the exact automated conformance fixture and clearly discloses that boundary for other 5.7 patches;
- gives Connections and Schema a persisted, draggable 20–80% vertical split that defaults to the middle and supports keyboard resizing;
- reduces sidebar overhead with compact connection rows, collapsed schema search, icon-only refresh controls, and quieter Offline and schema states;
- sizes short query-result columns to their loaded content while preserving the established 180px default cap for larger values and manual resizing up to 640px; and
- adds persisted table font-family and 10–20px text-size settings for query results and editable table grids.

QueryNot remains local-first and sends no telemetry or database information. MySQL 5.7 remains an end-of-life legacy compatibility target rather than a recommendation; malformed, ambiguous, and unrecognized MySQL/MariaDB identities continue in query-only mode. TLS verification, destructive-query confirmation, transaction-state checks, bound mutations, optimistic conflict detection, and atomic rollback are unchanged.

Updater signatures authenticate release payloads but are not Windows Authenticode, Apple Developer ID/notarization, or Linux repository signatures. Windows may show an unknown-publisher warning, macOS may require its per-application Open Anyway flow for the unnotarized build, and Linux desktop or package tools may show an untrusted-source warning. Do not disable an operating-system security control globally; verify the downloaded installable package against `SHA256SUMS` before installation.

The platform matrix remains Windows 11 x86-64, Linux x86-64 through AppImage/DEB/RPM, and macOS 13 or later on Intel and Apple silicon. MySQL 5.7.44 remains the exact certified 5.7 fixture; the broader well-formed 5.7.x write path is compatibility behavior, not a claim that every patch or vendor build was independently tested.
