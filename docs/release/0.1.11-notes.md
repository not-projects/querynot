# QueryNot 0.1.11

This patch release tightens the SQL-completion experience and makes cancellation of a paused result cursor finish cleanly.

Highlights:

- keeps the completion popup visible outside the bounded SQL editor while preserving QueryNot theme tokens and UI scaling;
- loads missing column metadata on demand through the existing native metadata session, so referenced-table columns appear in `WHERE` expressions and in `SELECT` lists even when the statement's `FROM` clause follows the caret;
- reuses and bounds completion metadata without opening a query execution session or bypassing staged-mutation safeguards;
- treats an adapter-emitted cancellation event as terminal even when a separate MySQL-family `KILL QUERY` confirmation is unavailable; and
- closes paused result state, freezes elapsed time, disables Cancel, and unlocks the editor after cancellation.

QueryNot remains local-first and sends no telemetry or database information. Connection credentials, direct database access, native session isolation, query-history persistence, TLS verification, destructive-query safeguards, file boundaries, and updater-signing boundaries are unchanged.

Updater signatures authenticate release payloads but are not Windows Authenticode, Apple Developer ID/notarization, or Linux repository signatures. Windows may show an unknown-publisher warning, macOS may require its per-application Open Anyway flow for the unnotarized build, and Linux desktop or package tools may show an untrusted-source warning. Do not disable an operating-system security control globally; verify the downloaded installable package against `SHA256SUMS` before installation.

The platform and database matrix is unchanged from 0.1.10: Windows 11 x86-64, Linux x86-64 through AppImage/DEB/RPM, macOS 13 or later on Intel and Apple silicon, SQLite format 3, and the published MySQL/MariaDB fixture matrix. Frontend, Chromium, Rust workspace, contract, traceability, formatting, dependency-policy, and production-build checks passed during development. Native hardware, Windows Narrator/WebView2 UI Automation, operating-system Contrast Themes, vault, performance, dogfood, and external beta observations remain follow-up evidence rather than release claims.
