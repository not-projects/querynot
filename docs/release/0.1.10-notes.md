# QueryNot 0.1.10

This release extends SQL completion with schema-aware columns and engine-aware functions, while making the completion popup fully navigable from the keyboard. Database sessions, SQL execution, local persistence, and safety boundaries are unchanged.

Highlights:

- suggests columns from tables and aliases referenced by the current statement when their structure metadata has been loaded;
- uses the last explicitly selected table's columns before a `FROM` relation has been entered, so projection lists can be completed naturally;
- offers SQLite, MySQL, and MariaDB built-in functions only in expression contexts, including `from_unixtime` and version-gated MySQL functions;
- scopes relation, alias, column, keyword, and function suggestions to appropriate statement positions instead of presenting one undifferentiated list;
- restores Arrow Up/Down and Page Up/Down movement through the completion popup;
- accepts the active suggestion with Tab while preserving Enter as a newline; and
- extends unit and Chromium regression coverage for statement context, metadata precedence, engine/version gates, keyboard navigation, acceptance, and editor focus.

QueryNot remains local-first and sends no telemetry or database information. Connection credentials, database access, native session isolation, query-history persistence, TLS verification, destructive-query safeguards, file boundaries, and updater-signing boundaries are unchanged.

Updater signatures authenticate release payloads but are not Windows Authenticode, Apple Developer ID/notarization, or Linux repository signatures. Windows may show an unknown-publisher warning, macOS may require its per-application Open Anyway flow for the unnotarized build, and Linux desktop or package tools may show an untrusted-source warning. Do not disable an operating-system security control globally; verify the downloaded installable package against `SHA256SUMS` before installation.

The platform and database matrix is unchanged from 0.1.9: Windows 11 x86-64, Linux x86-64 through AppImage/DEB/RPM, macOS 13 or later on Intel and Apple silicon, SQLite format 3, and the published MySQL/MariaDB fixture matrix. Chromium layout and keyboard completion proxies passed during development. Native hardware, Windows Narrator/WebView2 UI Automation, operating-system Contrast Themes, vault, performance, dogfood, and external beta observations remain follow-up evidence rather than release claims.
