# QueryNot 0.1.7

This release makes QueryNot’s everyday controls easier to scan and keeps advanced connection and preference options available without letting them dominate the main workflow.

Highlights:

- rebalances the application header so File stays with the product context while connection status, History, and Settings form one stable utility group;
- gives Run, Run all, Cancel, transaction mode, document actions, result context, filtering, copy, value inspection, export, and row-selection actions clearer tiers with consistent compact sizing;
- reorganizes Settings into purpose-based sections with a persistent action footer, independently scrolling preferences, and reachable reset controls at constrained sizes and high UI scales;
- rebuilds Add connection around connection details, transport security, credentials, and connection behavior, with explicit vault/session/no-credential choices and progressively disclosed client-certificate controls;
- starts SQLite connection setup with one explicitly selected and read-only-probed database file, keeps the full path behind the native boundary, and omits server-only reconnect controls; and
- captures filtered and sorted current-view row indexes only when Export is chosen, removing unnecessary continuous result-state synchronization.

QueryNot remains local-first and sends no telemetry or database information. Saving a connection does not connect it. Passwords, client-key passphrases, certificate contents, and sensitive local paths retain their existing native boundaries; TLS verification and destructive-query safeguards are unchanged.

Updater signatures authenticate release payloads but are not Windows Authenticode, Apple Developer ID/notarization, or Linux repository signatures. Windows may show an unknown-publisher warning, macOS may require its per-application Open Anyway flow for the unnotarized build, and Linux desktop or package tools may show an untrusted-source warning. Do not disable an operating-system security control globally; verify the downloaded installable package against `SHA256SUMS` before installation.

The platform and database matrix is unchanged: Windows 11 x86-64, Linux x86-64 through AppImage/DEB/RPM, macOS 13 or later on Intel and Apple silicon, SQLite format 3, the exact MySQL/MariaDB fixtures, and the bounded MySQL 5.7.x compatibility behavior documented for 0.1.6. Native hardware, vault, accessibility, performance, dogfood, and external beta observations remain follow-up evidence rather than release claims.
