# QueryNot 0.1.3

This Windows 11 x86-64 maintenance release keeps the SQL editor stable while typing and reorganizes the workbench around connection profiles without weakening per-tab database-session isolation.

Highlights:

- kept the same CodeMirror instance mounted and focused through normal typing while preserving targeted document, dialect, wrapping, and editable-state updates;
- nested query and table-data children beneath their connection profiles, with a dedicated Offline group for unbound files and drafts;
- kept Connect and Disconnect at profile level while lazily opening one isolated native session for each selected child and avoiding eager connections for unused restored tabs;
- added scoped retry for failed child-session opens, deduplicated concurrent opens, and treated pending opens as blockers for close, profile disconnect, and updater handoff;
- retained independent transactions, temporary objects, context, cancellation, and results for every child session; and
- moved CSV formula-prefix, NULL-token, and binary-format guidance into the expanded Export control instead of displaying it whenever rows exist.

QueryNot remains local-first and sends no telemetry or database information. The workspace persistence format remains backward compatible, and this release does not add a database migration or change the Tauri command contract.

The updater signature is not Windows Authenticode signing, so Windows may still show the unsigned-publisher warning documented in the installation guide. Installation saves recovery drafts and refuses the handoff while connection setup, a child-session open, query execution, transaction, or staged table edit is unresolved.

Support remains Windows 11 x86-64 with the SQLite, MySQL, and MariaDB matrix documented in the compatibility matrix. Windows 10, macOS, native Linux distribution, additional engines, cloud synchronization, accounts, telemetry, and external beta expansion remain unsupported or post-release work unless separately approved.
