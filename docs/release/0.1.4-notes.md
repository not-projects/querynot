# QueryNot 0.1.4

This Windows 11 x86-64 maintenance release repairs workbench readability and interaction while preserving QueryNot's local-first safety and isolated database-session lifecycle.

Highlights:

- restored compact horizontal tabs scoped to the selected connection or Offline group, with readable connection rows and local History in a non-resizing right-side drawer;
- defined deterministic editor, splitter, and result tracks, and synchronized wide virtualized results behind one horizontal scrollbar;
- made dark SQL completion readable, assigned Tab to completion acceptance, and standardized query and document actions on literal Windows Ctrl shortcuts;
- kept Settings usable during UI-scale preview and bounded every scaled dialog to the current viewport with fully reachable title and action areas;
- replaced font-symbol controls with shared accessible SVG icons, centered those icons inside their buttons, and flattened the main workbench hierarchy;
- moved table and view structure into connection-scoped workspace tabs with columns, keys, indexes, types, defaults, and generated fields while keeping row browsing explicit and lazy;
- made result-row selection explicit and added a side value subtab with soft wrapping, exact raw copy, and formatted JSON display; and
- kept active-tab close within its owning connection or Offline group, creating an empty same-group query when needed.

QueryNot remains local-first and sends no telemetry or database information. The workspace persistence format remains backward compatible, and this release does not add a database migration or change the Tauri command contract.

The updater signature is not Windows Authenticode signing, so Windows may still show the unsigned-publisher warning documented in the installation guide. Installation saves recovery drafts and refuses the handoff while connection setup, a tab-session open, query execution, transaction, or staged table edit is unresolved.

Support remains Windows 11 x86-64 with the SQLite, MySQL, and MariaDB matrix documented in the compatibility matrix. Windows 10, macOS, native Linux distribution, additional engines, cloud synchronization, accounts, telemetry, and external beta expansion remain unsupported or post-release work unless separately approved.
