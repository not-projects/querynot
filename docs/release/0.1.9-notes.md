# QueryNot 0.1.9

This release completes the next workbench redesign iteration. Context actions, document commands, result tools, and execution feedback now share a calmer hierarchy and consistent keyboard behavior without changing database sessions, SQL execution, local persistence, or safety boundaries.

Highlights:

- reworks saved-connection, schema-object, and workspace-tab context actions into compact keyboard-navigable menus with reliable dismissal, focus return, bounded positioning, and explicit destructive treatment;
- adds bounded tab move commands and a focused rename dialog that preserves the tab's SQL, connection, native session, and results;
- separates result copying from export configuration, keeping row-copy commands immediate while CSV safety, NULL-token handling, and server-order/current-view choices remain explicit in Export;
- clarifies execution feedback by keeping the overall result outcome and elapsed time in the Results heading, loaded-row counts with filtering, and per-statement details in the grid footer;
- moves SQL document actions into a keyboard command menu with active-group and local-file context, visible shortcuts, and explained disabled save actions while keeping Format in the editor toolbar;
- adds explicit queued/running rowless, statement-only success, zero-row, filter-empty, cancellation, failure, and populated result states; and
- extends Chromium regression coverage with accessible-name checks, focus-return and focus-visibility checks, plus a forced-colors layout proxy across the redesigned workbench.

QueryNot remains local-first and sends no telemetry or database information. Connection credentials, database access, native session isolation, query-history persistence, TLS verification, destructive-query safeguards, file boundaries, and updater-signing boundaries are unchanged.

Updater signatures authenticate release payloads but are not Windows Authenticode, Apple Developer ID/notarization, or Linux repository signatures. Windows may show an unknown-publisher warning, macOS may require its per-application Open Anyway flow for the unnotarized build, and Linux desktop or package tools may show an untrusted-source warning. Do not disable an operating-system security control globally; verify the downloaded installable package against `SHA256SUMS` before installation.

The platform and database matrix is unchanged from 0.1.8: Windows 11 x86-64, Linux x86-64 through AppImage/DEB/RPM, macOS 13 or later on Intel and Apple silicon, SQLite format 3, and the published MySQL/MariaDB fixture matrix. Chromium layout, keyboard, focus, and forced-colors proxies passed during development. Native hardware, Windows Narrator/WebView2 UI Automation, operating-system Contrast Themes, vault, performance, dogfood, and external beta observations remain follow-up evidence rather than release claims.
